# A10 — Brand strategy draft (for operator decision)

**Phase:** 3 Positioning · **Owner:** AGENT → OPERATOR (O2 decides) · **Depends on:** A1, A9 ·
**Feeds:** A11, O2, O3, A12 · **Budget:** read-only.

(Prepend `COMMON.md`. Fill placeholders.)

## Objective

Propose where `<<PROJECT>>` stands in the category, what it will and will not claim, and how it
speaks — as options with evidence, for the operator to decide in O2. Market execution (A11)
and visual design (A12/A14) are out of scope.

## Inputs

- `A1` (buyer language, pains, evaluation criteria, disconfirming evidence), `A9` (matrix,
  maps, unclaimed positions, self-assessment), `<<STRATEGY_DOCS>>`, and the product itself:
  read the code paths that *enforce* the things you want to claim (schema constraints,
  policies, published metrics) so proof points are SAYABLE, not aspirational.

## Method

Write the following, each grounded with citations to A1/A9 and file paths:

1. **Where we sit** — position on the A9 maps, in one paragraph, and the category term we
   use (with the alternatives buyers used in A1 and their counts).
2. **Position statement — three variants**, each ≤ 40 words, in different registers
   (mechanism-led, outcome-led, identity-led). For each: the A1 verbatims it echoes, the
   competitor it implicitly contrasts with, and the proof it depends on. These three go to O3
   for testing.
3. **Proof points** — the three to five things we can show, each tagged SAYABLE (file path or
   query), ROADMAP (dated plan) or GATED (decision id). A proof that is GATED cannot be in the
   position statement.
4. **Anti-positioning** — binding "never say" rules with the reason (legal, unprovable,
   category cliché, contradicts a value). Include how to handle our weakest public number
   honestly (the rule, not the spin).
5. **Voice** — five or six principles, each with a good/bad example pair drawn from our
   current copy, plus a three-question *register test* an author can apply to any sentence.
6. **Identity brief** (for A12, not a design): type direction, palette mode and what the
   accent is reserved for, signature device (what visual element carries the position),
   things to avoid because the category owns them (from A7 pattern counts). No hex values,
   no typeface names — directions only.
7. **Decisions handed to the operator** — a numbered list: the name (keep / change, with
   the cost of each now vs later), category term, the beachhead segment, the gating product
   decision(s), any rights/legal gates. For each: options, evidence, recommendation,
   consequence of not deciding.

## Output — `<<OUT>>/3-positioning/A10-brand-strategy-<<DATE>>.md`

COMMON header (Status: SYNTHESIS; add `PROVISIONAL — no buyer evidence` if A1 is missing).
Sections 1–7 · Sources.

## Done when

Three testable variants exist; every proof point carries a SAYABLE/ROADMAP/GATED tag with
its evidence; the voice section has example pairs from our own copy; section 7 is a list an
operator can answer in one sitting.

## Do not

- Do not decide the name, the segment or the packaging; frame them.
- Do not use a proof the product cannot show today unless labelled ROADMAP with a date.
- Do not write marketing copy; A15 does.

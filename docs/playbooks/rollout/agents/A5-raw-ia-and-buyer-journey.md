# A5 — Mission 1: Information architecture & buyer journey (raw)

**Phase:** 2 Research — design set · **Owner:** AGENT · **Depends on:** A8 screenshots (do
this *after* A8, or run A8 first in the same session) · **Feeds:** A9, A13 · **Budget:** browser
+ web; no paid calls.

(Prepend `COMMON.md`. Fill placeholders.)

## Objective

For each competitor, record how the public site is organised, how it moves a visitor toward
a commercial action, and how concretely it describes the product — so that A13 can design our
IA against evidence of what the category does and what it leaves undone. RAW.

## Inputs

- `<<COMPETITORS>>`; screenshots and manifest from A8; live browser access.

## Method

Visit each vendor **live** (not via a text-fetch summariser; if you must fall back to
text-fetch, mark every affected finding "text-fetch only" and re-verify when the browser is
available). For each vendor answer three questions with evidence:

1. **Navigation logic.** Transcribe the top nav verbatim (labels, order, dropdown children).
   Classify the organising principle: by Product, by Industry, by Threat/Use-case, by
   Solution, by Audience, or mixed. Note whether Pricing, Trial, Login, Docs/API, Resources,
   About are top-level. Note footer IA if it differs materially. Note mobile nav behaviour
   (from the mobile capture).
2. **Primary CTA.** Exact button copy, where it appears (header, hero, repeated count),
   and its destination (form fields required, demo vs trial vs contact vs self-serve signup).
   Record secondary CTAs. Record whether any path lets a visitor see the product without
   talking to sales (interactive demo, sample report, public data, docs).
3. **Product specificity vs abstraction.** Hero headline and sub verbatim. Does the site say
   what the product *is* (data, software, reports, people) within the first screen? Where is
   the first concrete artefact shown (screenshot, sample, number)? Score 1–5 with the
   evidence.

Then a **cross-vendor table**: vendor · nav principle · pricing visible? · trial? · demo-gated? ·
first concrete artefact position · specificity score.

## Output — `<<OUT>>/2-research/A5-raw-ia-navigation-<<DATE>>.md`

COMMON header (Status: RAW; list which vendors were live vs text-fetch). Per-vendor sections
1–3 with screenshot references · Cross-vendor table · Verbatim hero headline list ·
Corrections log (for Pass 2 fixes) · Sources. End with: *No strategic synthesis or
recommendations in this file.*

## Done when

Every vendor has verbatim nav, CTA copy + destination, and hero copy; every finding is
marked live or text-fetch; the cross-vendor table is complete; mobile nav is noted for each.

# Decision-log entry template

Append one block per decision to the project's decision log (append-only). Used by O2, O4,
O7 and by any step that resolves an open question.

```
### <DATE> — <short title> (playbook step <O2|O4|O7|…>)

**Question:** …
**Decision:** …
**Rejected:** option — why; option — why.
**Evidence:** A1 report ids / A9 §n / A3 table row / O3 scores …
**Confidence:** HIGH | MEDIUM | LOW
**Review date:** <date> — what would reopen it.
**Unblocks:** steps and open-task ids.
**Doc edits required:** file § — change (agent-executable list).
```
